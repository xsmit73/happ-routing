# happ-routing

Самообновляемый профиль маршрутизации для Happ.

- База — профиль RoscomVPN DEFAULT (списки обновляются автором).
- Торренты НЕ блокируются.
- Все сайты в зонах .ru/.su/.рф и российские сервисы на других доменах идут напрямую.
- Каждые 6 часов GitHub Actions пересобирает профиль; если что-то изменилось — коммитит.

Ссылка для 3x-ui («Правила маршрутизации»):

    https://raw.githubusercontent.com/xsmit73/happ-routing/main/happ-routing.json

Свои правки — в `custom.json` (после сохранения профиль пересоберётся сам).
Для ручного импорта на устройство — содержимое `happ-routing.deeplink`.
